# SCT_WD_3
A modern Tic-Tac-Toe game with two gameplay modes — Player vs Player (PvP) and Player vs Computer (PvC) — built using HTML, CSS, and JavaScript. Featuring sleek gradient visuals, responsive design, and game logic for win/draw detection. 



---

## ✨ Key Features

- ❌⭕ Classic Tic-Tac-Toe gameplay  
- 🆚 Two modes: **PvP** and **PvC**  
- 🔄 Restart game anytime  
- 🧠 Intelligent win/draw logic  
- 🎨 Eye-catching gradient UI  
- 

---

## 🛠️ Built With

- **HTML5** — Markup and structure  
- **CSS3** — Styling and **gradients**  
- **JavaScript** — Game logic and interactivity
